# Stationary Arm RoArm M3

`platforms/stationary_arm_roarm_m3/` is the robot-specific composition layer for the first platform.

This subtree should eventually assemble:

- smart-servo backend configuration,
- joint mapping,
- limit configuration,
- firmware application wiring,
- communication topics and command handling specific to the stationary arm.

This is not the place for generic smart-servo protocol code or generic control logic.
